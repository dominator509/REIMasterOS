# Rollback Checklist

- [ ] Rollback trigger identified.
- [ ] Rollback decision owner assigned.
- [ ] Impact scope identified.
- [ ] Application version to restore identified.
- [ ] Config changes to revert identified.
- [ ] Database migration/data considerations reviewed.
- [ ] Backup/restore path confirmed if needed.
- [ ] Feature flags/provider routes to disable identified.
- [ ] Live campaigns/providers paused if needed.
- [ ] Rollback executed.
- [ ] Smoke tests run.
- [ ] Error rate/queues/provider health monitored.
- [ ] User/internal communication sent if applicable.
- [ ] Incident notes updated.
- [ ] Postmortem created for SEV-1/SEV-2.

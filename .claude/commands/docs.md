# /docs — Search or update project documentation

#

# Usage: /docs [search <query>|update <file>|index]

#

# search — Search all project docs for a query

# update — Update a specific documentation file

# index — Show the documentation map

Project docs live in repo root (*.md) and .agent/ directory.
Cross-reference between ARCHITECTURE.md, ROADMAP.md, specs, and ExecPlans.

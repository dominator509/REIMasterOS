# /execplan — Work with active ExecPlan
#
# Usage: /execplan [list|active|create <name>]
#
# list    — List all ExecPlans with status
# active  — Show the currently active ExecPlan
# create  — Create a new ExecPlan from template

Read AGENTS.md, COMMANDS.md, .agent/PLANS.md, then the active ExecPlan.
Proceed through milestones autonomously. Update Progress after each milestone.
Stop only on AGENTS.md STOP conditions.
